# Iris Flower Classification

## About the Project

This is my first Data Science internship project with Oasis Infobyte. The goal is to build a machine learning model that can identify different types of iris flowers using their measurements.

The model will work with three flower species: Setosa, Versicolor, and Virginica. I'll use Python to explore the dataset, create visualisations, train different models, and compare their results.

## What I'm Working On

- Exploring the Iris dataset and checking the data for missing values.
- Using graphs to understand the differences between the three flower species.
- Looking at which measurements help distinguish the species.
- Training at least two machine learning classification models.
- Comparing the models to see which one performs best.
- Explaining my results and what I learned from the project.

## Tools I'm Using

- Python
- Jupyter Notebook
- pandas
- scikit-learn
- matplotlib
- seaborn

## Dataset

I'll use the Iris dataset available directly from `scikit-learn`, so there's no need to download it separately.

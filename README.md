# OIBSIP – Data Science Internship

## About the Internship

This repository contains the projects completed as part of my Data Science internship at Oasis Infobyte (OIBSIP).

The projects provided an opportunity to work with Python, data analysis, data visualisation and machine learning while solving different practical problems using real-world datasets.

Each task is organised in its own folder, with its Jupyter Notebook, dataset, screenshots and project documentation.

## Projects

### Task 1: Iris Flower Classification

A classification project that uses the Iris dataset to predict flower species based on their measurements.

**What I worked on:**
- Loading and exploring the Iris dataset.
- Preparing data for machine learning.
- Training classification models.
- Comparing Logistic Regression and K-Nearest Neighbors.

**Models used:**
- Logistic Regression
- K-Nearest Neighbors (KNN)

### Task 2: Unemployment Analysis

An exploratory data analysis project using unemployment data from India.

**What I worked on:**
- Exploring unemployment trends.
- Analysing unemployment rates across different regions.
- Comparing regional unemployment figures.
- Creating visualisations to identify patterns in the data.

**Libraries used:** Pandas, Matplotlib and Seaborn.

### Task 3: Car Price Prediction

A machine learning project focused on predicting the selling price of used cars using vehicle information.

**What I worked on:**
- Exploring and preparing vehicle data.
- Analysing the relationship between vehicle features and selling prices.
- Preparing data for regression modelling.
- Building a model to estimate car prices.

### Task 4: Email Spam Detection

A text classification project focused on distinguishing spam messages from legitimate messages using machine learning.

**What I worked on:**
- Cleaning and preparing text data.
- Converting text into numerical features.
- Training and comparing classification models.
- Evaluating model performance using classification metrics and a confusion matrix.

**Models used:**
- Multinomial Naive Bayes
- Logistic Regression

*NB: The dataset used for this task is the SMS Spam Collection dataset.*

### Task 5: Sales Prediction Using Python

A regression project that predicts product sales based on advertising expenditure across TV, Radio and Newspaper channels.

**What I worked on:**
- Exploring advertising and sales data.
- Analysing correlations between advertising channels and sales.
- Training and comparing regression models.
- Evaluating predictions using MAE, RMSE and R².
- Analysing feature importance.

**Models used:**
- Linear Regression
- Random Forest Regression

**Best model:** Random Forest Regression, with an R² score of 0.9813.

## Running the Projects

### Requirements

Python and Jupyter Notebook are required to run the notebooks.

Install the commonly used libraries with:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Steps

1. Clone or download this repository.
2. Open the folder for the task you want to explore.
3. Open a terminal in that folder.
4. Install any additional libraries required by that particular project.
5. Start Jupyter Notebook:

```bash
jupyter notebook
```

6. Open the relevant `.ipynb` file and run the cells.

Make sure the datasets are available in their respective `data` folders before running the notebooks.
